# Схема разметки ключевых точек (v2)

Подробная иллюстрированная инструкция для тех, кто не знает анатомию:
[annotation_guide.html](annotation_guide.html). Там же, в инструменте, для каждой точки
показан пример.

Зачем точки: критерии ТЗ геометрические (наклон оси, захват таза, поля кадра, малый вертел).
По точкам сервис измеряет их в градусах и миллиметрах. Эти же точки размечают синтетические
нарушения ([dxaqc/synth.py](../dxaqc/synth.py)).

## Позвоночник: 4 точки (v2)

| Код | Что ставить | `N` |
|---|---|---|
| `col_top` | середина светлого столба у верхнего края снимка | — |
| `col_bottom` | середина столба на уровне верхушек крыльев таза; если крыльев нет — у нижнего края | — |
| `crest_a` | верхушка крыла таза слева на снимке | крыла нет в кадре |
| `crest_b` | верхушка крыла таза справа на снимке | крыла нет в кадре |

Плюс рамки вокруг инородных тел: тонкие очень яркие предметы. Рёбра не обводить.

Почему не уровни позвонков (v1: Th12, L1–L5). На снимках DXA 300×300 px уровни трудно
различить даже специалисту. Все 6 нарушений укладки позвоночника в обучающих данных — это
«таз не попал в кадр», и такие случаи ловят точки крыльев. Нехватку сверху (не видно Th12)
оцениваем по расстоянию от уровня крыльев до верхнего края кадра (`MIN_SPINE_SPAN_MM`,
калибруется по нормальным снимкам).

## Бедро: 9 точек и размер малого вертела

| Код | Что ставить | `N` |
|---|---|---|
| `fh_c` | центр головки (шара) | — |
| `fh_top` | верх головки | — |
| `fn_c` | центр шейки в самом узком месте | — |
| `gt_top` | верхушка большого вертела | — |
| `gt_lat` | наружный край большого вертела | срезан краем кадра |
| `lt` | вершина малого вертела | контур гладкий, бугорка нет |
| `isch` | низ седалищной кости | нет в кадре |
| `shaft_p` | середина диафиза под малым вертелом | — |
| `shaft_d` | середина диафиза у нижнего края | — |

Размер малого вертела `lt_size`: 1 — не виден, 2 — норма, 3 — слишком большой (рис. 5 ТЗ).
Протезы отмечаются флагом `skip` (клавиша `S`).

## Процесс

- Инструмент: `tools/annotator/index.html`, запуск из корня проекта:
  `python3 -m http.server 8765 --bind 127.0.0.1`, затем открыть `http://127.0.0.1:8765/tools/annotator/`.
  Для команды: `dist/annotation_kit.zip` (`scripts/make_annotation_kit.py`), внутри `start_annotator.sh`/`.bat`.
- Каждое 10-е исследование получают все разметчики: по нему считается согласованность.
- Экспорт JSON, затем `python scripts/merge_keypoints.py dxa_keypoints_*.json`.
- Старые записи позвоночника v1 при загрузке мигрируют: крылья и рамки сохраняются,
  уровни позвонков удаляются.

Снимки — медицинские данные организатора. Не выкладывать ни их, ни набор для разметки.
