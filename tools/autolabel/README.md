# Полуавтоматическая разметка ключевых точек (как делалась v2)

Результат: `data/train/keypoints_claude_export.json` (формат инструмента, открывается через «Импорт JSON»)
и `data/train/keypoints.json` (после `scripts/merge_keypoints.py`).

Процесс, выполнялся вслепую, без экспертных меток:

1. **Позвоночник.** `spine_pre.py` предлагает центральную линию столба (динамическое программирование
   по яркости) и верхушки крыльев таза. Все 99 снимков проверены глазами по увеличенным фрагментам;
   поправки и рамки инородных тел лежат в `spine_fix.py`. Бледные крылья помечены `unsure`.
2. **Бедро.** Алгоритм (`hip_pre.py`) оказался ненадёжен из-за разного контраста снимков. Поэтому
   опорные точки (головка, шейка, вертелы, седалищная кость) поставлены вручную по CLAHE-снимкам
   с сеткой 10 px (`hip_manual.py`). Большой вертел затем примагничен к краю кости; 46 крупных сдвигов
   проверены глазами, один отменён.
3. **Малый вертел.** `lt_pass.py` измеряет выпуклость внутреннего контура кости под шейкой
   (скачки контура на таз отбрасываются). По ней задаётся класс: 1 — меньше 1 px, 2 — 1–4 px,
   3 — от 4 px. Все случаи класса 3 проверены глазами. Пограничные (0.8–1.3 px) помечены `unsure`.

Скрипты сохранены как запись процесса. Пути в них указывают на рабочую папку сессии.

Проверка по экспертным меткам проводилась уже после фиксации разметки:

| Правило | Результат |
|---|---|
| Наклон оси позвоночника | AUC 0.88 |
| Таз не в кадре → нарушение укладки | 5 из 6 нарушений, ложных 5 из 93 |
| Рамки инородных тел | 15 из 17 размеченных артефактов |
| Нижнее поле бедра (мм) | AUC 0.92 |
